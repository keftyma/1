Описание DTD и XML-документа расписания

Данный репозиторий содержит пример описания структуры XML-документа с помощью DTD. 

Проект описывает расписание занятий в спортивных комплексах. 

Структура документа

Корневой элемент: `timeTable`
Сложные элементы:
`complexes` — содержит список спортивных комплексов.
`lessons` — содержит список занятий.
Простые элементы: `complex` (с полями `name`, `address`), `lesson` (с полями `date`, `time`).
